# Publication asset audit

The distributable visual inputs are the nine texture maps in `assets/textures/`, the authored scene in `assets/simulation/reference-scene.blend`, its exported `room.glb` and `robot.glb`, and authored simulation renders/recordings. Scene geometry is an implementation informed by visual references, not vendor CAD or a surveyed hospital model. This audit does not assign a new license to the project's authored code or geometry.

The three Poly Haven materials—Oak Veneer 01, Linoleum Brown and Rough Linen—contain nine JPEG diffuse, OpenGL-normal and roughness maps, totaling 6,686,020 bytes. Poly Haven supplies these texture assets under [CC0](https://polyhaven.com/license). Their source URLs, artist credits, acquisition timestamps, channel paths and verified file hashes are preserved in [pbr-materials.json](pbr-materials.json). The three `*-files.json` records preserve the API download manifests. The Blender authoring script loads these texture assets; it does not load the cached hospital photographs into the exported scene.

The two official Stanford/UCLA room photographs are **local inspection references only**. No training or redistribution permission was established. Their source links and rights limitations remain documented in [hospital-reference-images.json](hospital-reference-images.json), but the image files in `assets/references/` are excluded from both Git and the Docker build context. Public pages should link to the original publishers rather than serve these cached photographs.

The user-supplied Bracket Bot PDF and three videos, together with their extracted frames, contact sheets and text under `artifacts/references/`, are also excluded. Documents that refer to those local inspection artifacts intentionally do not include the artifacts in a fresh repository checkout. The [public Bracket Bot source audit](bracketbot-public-audit.json) records the limited public repository checks; the reconstruction remains a hardware approximation.

Publication exclusions also cover runtime databases and task/learning history, credential-bearing environment variants, local Vercel state, browser traces/caches, authoring backups, and the redundant full Poly Haven catalog cache. `.env.example`, useful synthetic result reports, authored browser screenshots/video, original `.blend`, GLBs, and CC0 texture maps remain eligible for version control. Ignore rules do not remove an already tracked file: the final staged-file review must confirm the excluded paths are absent before a commit is published.
